# Sea Battle - Морской Бой

Игра "Морской бой" по локальной сети.

## Описание
- Вы можете создать комнату или подключиться к существующей в локальной сети.
- После подключения начинается фаза расстановки кораблей. После того как оба игрока расставят корабли, им нужно нажать на кнопку Ready.
- Корабли:
    - 1 корабль на 4 клетки
    - 2 корабля на 3 клетки
    - 3 корабля на 2 клетки
    - 4 корабля на 1 клетку
- Когда все игроки готовы, начинается основная игра, в которой игроки по очереди пытаются попасть по кораблю противника.
- Виды атак:
  - Стандартный выстрел (одна клетка)
  - Горизонтальная линия (весь ряд)
  - Вертикальная линия (весь столбец)
- Когда все корабли одного из игроков потонут, игра закончится.

## Требования

- .NET 9.0 или выше
- MAUI

## Установка и запуск

1. Клонируйте репозиторий: `git clone https://github.com/yourusername/sea-battle.git`
2. Откройте решение: `SeaBattle.sln` в папке `src`
3. Запустите сборку и запуск для нужной платформы

## Структура проекта

### Основные компоненты:
- `SeaBattle.Models` - игровые модели и логика
- `SeaBattle.Services` - сервисы для управления игрой
- `SeaBattle.Server` - сетевая реализация

### Models
#### GameEngine.cs
Назначение: Основной движок игры, управляющий всей игровой логикой

Cвойства:
- `PlayerBoard`, `EnemyBoard` - игровые поля 10x10
- `CurrentState` - текущее состояние игры (расстановка, ходы, завершена)
- `IsPlayerTurn` - флаг хода игрока
- `PlacedShipsCount`, `TotalShipsCount` - статистика по кораблям
- `HasLineHorizontalAttack`, `HasLineVerticalAttack` - доступность спецатак
- `SelectedSpecialAttack` - выбранный тип атаки

Методы:
- `PlaceShip()` - размещает корабль на поле игрока
- `ExecuteAttack()` - выполняет выстрел по вражескому полю
- `ProcessEnemyShot()` - обрабатывает выстрел противника
- `CheckWinCondition()` - проверяет условия победы
- `ExecuteLineHorizontalAttack()`, `ExecuteLineVerticalAttack()` - спецатаки

#### Перечисления
- `GameState` - состояния игры: расстановка, ход игрока1, ход игрока2, завершена
- `CellState` - состояния клетки: пусто, корабль, попадание, промах
- `AttackType` - типы атак: стандартная, вертикальная линия, горизонтальная линия

#### Ship.cs
Назначение: Модель корабля

Свойства:
- `Size` - размер корабля (1-4)
- `X`, `Y` - координаты размещения
- `IsHorizontal` - горизонтальная ориентация
- `IsPlaced` - флаг размещения на поле

#### Room.cs
Назначение: Модель игровой комнаты для сетевой игры

Свойства:
- `IP` - IP-адрес сервера
- `Name` - имя комнаты/игрока

### Services

#### BoardService.cs
Назначение: Сервис управления игровыми досками и их отображением

Конструктор: Принимает GameEngine, Grid'ы игрока и противника, обработчики кликов

Методы:
- `CreateGameBoards()` - создает игровые сетки 10x10
- `UpdateBoardDisplay()` - обновляет отображение досок
- `UpdateGrid()` - обновляет отдельную сетку на основе CellState

### Server

#### GameServer.cs
Назначение: Основной серверный менеджер, управляет сетевым взаимодействием

Свойства:
- `client`, `server` - TCP клиент и сервер
- `discovery` - сервис обнаружения в сети
- `isServerMode` - режим сервера/клиента
- `username` - имя пользователя

Методы:
- `StartServer()` - запускает серверный режим
- `ConnectToServer()` - подключается к удаленному серверу
- `SendMessage()` - отправляет сообщение по сети

#### NetworkMessageHandler.cs
Назначение: Обработчик сетевых сообщений, парсит и направляет команды

Конструктор: Принимает GameEngine, GameServer, делегаты для взаимодействия с UI

Методы:
- `OnMessageReceived()` - основной обработчик входящих сообщений
- `HandleShotMessage()` - обработка сообщения о выстреле
- `HandleResultMessage()` - обработка результата выстрела
- `HandleSpecialAttackMessage()` - обработка спец-атак

#### AttackHandler.cs
Назначение: Обработчик специальных атак, управляет логикой расширенных атак

Конструктор: Принимает GameEngine, GameServer и делегаты для UI

Основные методы:
- `ExecuteSpecialAttack()` - выполняет спец-атаку игрока
- `ProcessEnemySpecialAttack()` - обрабатывает спец-атаку противника
- `ProcessHorizontalLineAttackOnPlayer()` - обработка горизонтальной линии
- `ProcessVerticalLineAttackOnPlayer()` - обработка вертикальной линии

#### TcpMessageServer.cs
Назначение: TCP сервер для приема подключений и сообщений

Конструктор: Инициализирует сервер на порту 8080

Методы:
- `StartListeningAsync()` - запускает прослушивание порта
- `StopListening()` - останавливает сервер
- `SendMessageToClient()` - отправляет сообщение клиенту
- `HandleClientAsync()` - обработчик клиентских подключений

События:
- `MessageReceived` - получено сообщение
- `ClientConnected` - подключен клиент

#### TcpMessageClient.cs
Назначение: TCP клиент для подключения к серверу и обмена сообщениями

Cвойства:
- `IsConnected` - статус подключения

Основные методы:
- `ConnectToServer()` - подключается к TCP серверу
- `SendMessageAsync()` - отправляет сообщение
- `StartReading()` - запускает чтение входящих сообщений

События:
- `MessageReceived` - получено сообщение от сервера

#### ServerDiscovery.cs
Назначение: UDP сервис для обнаружения игровых серверов в локальной сети

Конструктор: Использует порт 8081 для широковещательных рассылок

Методы:
- `StartBroadcasting()` - начинает широковещательную рассылку о сервере
- `StartListening()` - начинает прослушивание сетевых рассылок
- `Stop()` - останавливает все операции
- `SendBroadcast()` - отправляет UDP broadcast сообщение

События:
- `ServerFound` - обнаружен сервер в сети
